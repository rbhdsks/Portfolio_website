# Previous portfolio source

`previous-site/` keeps the files retired when the repository was simplified.
Source snapshot: `a88fad6` (the first minimal-page commit).

Included: Jekyll configuration, layouts, includes, Sass, old pages, projects,
publications, CV/download files, assets, unused images, Docker and Node setup,
scripts, notebooks, and previous READMEs. The original `.gitignore` is also kept.

The active profile photo remains at `../images/profile.png` relative to this
archive folder. The existing `LICENSE` and domain file stay at the repo root.

These are reference files, not an independently runnable copy: internal paths
still reflect their original root locations. Use Git history to recover the
complete old layout if needed. Restoring the Jekyll version also requires
reconsidering the root `index.html` and `.nojekyll` files.

Nothing here participates in generating the current homepage. Files in this
public repository, including this archive, remain publicly accessible.
